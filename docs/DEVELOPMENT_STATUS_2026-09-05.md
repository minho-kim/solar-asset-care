# 🛠️ 실제 서비스 개발·검증 현황

- 기준일: 2026-09-05 (한국시간)
- 공개배포: 보류. 기존 공개 데모는 변경하지 않았다.
- 대상: `solar-asset-care`의 로컬 운영 화면과 독립 Supabase 프로젝트만 변경했다.
- 판단: 주요 점검·발행 흐름은 실제 계정으로 시험했다. 요구서 전체 구현 및 상용 검수 완료 상태는 아니다.

## ✅ 이번에 실제 저장·사용하도록 연결한 기능

### 계산·촬영 기준

관리자의 ‘계산·촬영 기준’에서 발전시간, 열화율, 보정계수, 단가, 성능비 구간, 일사량·풍속·각도·거리, 온도차 기준과 이상유형별 개선가능비율을 등록한다. 적용 시작일과 변경 사유를 남기며 기존 판본을 덮어쓰지 않는다. 확인되지 않은 단가·촬영 기준은 자동으로 활성화하지 않았다.

REC 단가는 원/kWh 단위다. 원/MWh 자료는 1,000으로 나누어 입력해야 한다. 기본으로 표시하는 일부 숫자는 요구서의 초기 참고값이며 검증된 운영 단가가 아니다.

### 촬영조건·발전량 평가

관리자·배정 전문가가 촬영조건, 측정 시각·출처, 분석기간·실발전량·출처와 예상 수리비를 입력한다. 설비용량·설치연도는 저장된 발전소에서 가져오고 서버가 계산한다. 화면에서 결과값을 조작해 보내도 저장 결과로 쓰지 않는다.

분석기간은 양 끝 날짜를 포함하고 실발전량과 기대발전량의 기간을 일치시킨다. 손실량은 0 이상으로 표시한다. 회수기간은 해당 기간의 회수가능액을 365일로 환산해 계산하며, 금액은 원 단위 반올림 표시·내부 계산값은 정밀도를 유지한다. 이 계산은 입력 기반 추정이며 일사 계측으로 산출한 IEC 성능비가 아니다.

일사량·풍속·각도·거리 경고가 있으면 보고서 검토 요청이 차단된다. 관리자만 사유를 기록해 예외 승인할 수 있다. 전문가는 예외 승인을 할 수 없으며 평가를 다시 수정하면 종전 예외 승인을 자동 승계하지 않는다. 다른 사람이 먼저 저장한 평가를 덮어쓰지 않도록 변경 차수를 확인한다.

### 전문가 수동 소견·수정

시스템 후보가 없더라도 수동 소견을 등록할 수 있다. 이상 유형, 심각도, 모듈 위치, 원본과 이미지 내 영역, 측정 온도·온도차, 측정 근거와 권고 조치를 기록한다. 기존 후보를 수정 채택하거나 제외할 수 있고 변경 전후와 담당자·시각을 보관한다. 제외는 기록 삭제가 아니다.

온도 수치를 입력하려면 별도 측정 근거가 필요하다. 색상 점수를 섭씨 온도로 바꾸지는 않는다. 내부 원본 미리보기와 기존 영역 표시는 연결했으나 고객용 마스킹·열화상 마커 뷰어는 별도 남은 기능이다.

### 검토 보관본과 PDF 발행

검토 요청 시점의 발전소·촬영조건·계산 기준·계산 결과·채택 소견·후속 조치·원본 목록을 하나의 보관본으로 고정한다. 이후 원자료를 수정해도 검토·승인·발행 보고서 내용은 바뀌지 않는다. 수정 요청이나 승인 취소 후 재검토하면 새 보관본을 만들고 이전 검토 내용은 감사기록에 남긴다.

관리자가 ‘최종 발행’을 누르면 서버가 승인된 보관본으로 PDF를 만들고 비공개로 보관한 뒤 발행한다. PDF 저장 실패 시 발행 상태로 넘어가지 않는다. 반복 요청은 기존 파일을 재사용하며 덮어쓰기를 허용하지 않는다. 의뢰인은 발행된 본인 보고서만 다운로드할 수 있고, 회수하면 같은 로그인 상태에서도 접근을 잃는다. 이미 내려받은 파일까지 원격 삭제하는 기능은 아니다.

PDF는 텍스트·계산·소견 중심의 1차 서식이다. 한글 글꼴을 포함하고 A4, 최소 11pt, 자동 페이지 나눔을 적용했다. 열화상 이미지·마커·지도·경제성 차트는 아직 포함하지 않는다.

### 실제 등록 오류 수정

발전소를 저장한 직후 저장 결과를 읽는 과정에서 권한 확인이 새 행을 보지 못해 등록 전체가 취소됐다. 관리자·배정 전문가의 기존 접근 범위를 유지하면서 발전소·점검·수동 소견 저장 결과를 정상적으로 읽도록 수정했다.

## 🧪 검증 결과와 범위

관리자 로그인 후 추가 브라우저 시험에서 발견한 점검 예정·마감 시각의 현지 시간대 의존과 모바일 상단 아이콘 이름 누락을 수정했다. 점검 일정과 기본 번호 날짜는 한국시간을 사용한다. 과거 저장값은 일괄 수정하지 않았다. 인증·권한·데이터 구조는 변경하지 않았다.

| 검증 | 결과 | 한계 |
|---|---|---|
| 자동 코드 검사 | 29개 통과 | 제출 버튼 연결, 계산·날짜 경계, 실제 점검 저장식의 시간대 독립성, 아이콘 이름, PDF 재현성·글꼴 포함 검사이며 전체 화면 검사가 아님 |
| 타입 검사·정적 검사·프로덕션 빌드 | 통과 | 공개 호스트 배포 검증은 아님 |
| 데이터베이스 업무·권한 시험 | 통과 | 두 조직, 관리자·배정/미배정 전문가·연결/미연결 의뢰인. 하나의 취소되는 시험 트랜잭션으로 실행 |
| 실제 Auth 세션·API·파일 시험 | 16개 통과 | 임시 사용자 5명·조직 2개, 실제 파일 업로드·서버 PDF 생성·의뢰인 다운로드·접근 차단. 합성 자료 1건이며 실제 고객 3건 검수와 다름 |
| PDF A4·한글·최소 11pt | 통과 | 생성 PDF 2쪽을 렌더링하고 글자 크기·경계·단위 문자를 확인 |
| 신규 모바일 화면 직접 조작 | Chrome 반응형 시험 통과 | 390px 메뉴 12개, 320px 주요 양식 확인. 별도 조직에서 등록·평가·소견·보고서 발행·의뢰인 조회 수행. 휴대폰·iOS Safari 실기 검수는 아님. 브라우저 파일 선택은 확장프로그램 권한으로 미검증 |
| 보안 진단 | 경고 1건 남음 | 유출 비밀번호 차단 미활성. 유료 플랜·설정 변경하지 않음 |

실제 세션 시험은 원본 업로드와 체크섬 확인 → 전문가 수동 판정·서버 계산 → 검토 → 관리자 승인 → PDF 보관 → 발행 → 의뢰인 다운로드까지 진행했다. 타 조직·타 의뢰인·익명 접근 거부, 전문가 승인 거부, PDF 덮어쓰기 거부, 원자료 변경 후 내용 불변, 회수 후 접근 거부를 확인했다. 이 시험은 브라우저 클릭 시험이나 방사온도 분석 정확도 시험이 아니다.

위 API 시험과 별개로 Chrome 화면 조작 시험도 진행했다. 모바일에서 입력·등록한 합성 자료로 보고서 초안 → 검토 → 승인 → 발행을 완료했고, 다운로드된 PDF가 서버 보관본과 일치함을 확인했다. 브라우저 파일 선택은 자동화 확장프로그램의 파일 접근 권한 때문에 중단했으며, 그 이후 화면 시험에 필요한 원본만 합성 계정의 정상 API로 등록했다. 이를 브라우저 업로드 성공으로 간주하지 않는다.

모든 임시 계정·조직·업무 행·Storage 객체는 정리했다. 사용자 계정, 비밀번호와 기존 운영 조직은 변경하지 않았다. 로컬 시험 PDF만 재검증용으로 남겼으며 Git 대상에서 제외했다.

## 🧭 집에서 확인할 순서

1. 관리자 로그인 후 ‘내 계정’에서 임시 비밀번호를 변경한다.
2. ‘계산·촬영 기준’에서 실제 사용할 값과 적용 시작일·출처를 등록한다.
3. 발전소의 설비용량·가동 시작일을 확인하고 점검과 전문가를 배정한다.
4. 원본 업로드 → ‘촬영조건·발전량’ 저장 → ‘후보 판정’에서 채택·수정·제외한다.
5. 보고서 초안 생성 → 검토 요청 → 보관 내용 확인 → 승인 → 최종 발행한다.
6. 연결된 의뢰인 계정에서 보고서와 ‘보관 PDF 다운로드’를 확인한다.

## 개발 재검증

- `demo-site/`: `npm test`, `npx tsc --noEmit`, `npm run lint`, `npm run build`.
- DB: `supabase/tests/operational_workflow.sql`은 최종 `ROLLBACK`까지 전체 실행한다.
- 실제 세션: 로컬 서버 실행 후 `SOLAR_ACCEPTANCE_RUN=1 node scripts/verify-live-workflow.mjs`. 지정된 개발 프로젝트에 합성 자료만 생성·정리한다. 자격증명은 CLI와 프로세스 메모리에서만 사용한다.
- PDF 글꼴은 저장소의 정적 파일을 사용한다. 향후 호스트에서는 `REPORT_ASSET_ORIGIN`을 신뢰할 수 있는 실제 주소로 명시해야 한다. 공개 호스팅은 아직 검증·승인하지 않았다.
- Supabase 스킬의 변경 이력·최소 권한·검증 원칙을 따라 새 표의 익명·직접 쓰기를 차단하고 업무 함수·역할 시험을 추가했다. PDF 스킬의 렌더 검증에서 CFF 글꼴 문제를 발견해 정적 TrueType으로 교체했다.
