# 📄 게스트 샘플 보고서 출력

- 요청: 게스트 화면에서 실제 출력할 수 있는 샘플 보고서 한 부 제공.
- 대상: 기존 공개 SolarScope 사이트의 게스트 보고서 메뉴. 별도 상용 호스트 이전이나 공개 범위 확대는 아니다.
- 변경: PDF 새 탭 열기·다운로드 링크, 고정 샘플 PDF, 재생성 스크립트와 검증. 실제 보고서 출력 함수는 명시적인 샘플 옵션일 때만 샘플 머리말·꼬리말과 안내를 넣는다. 기존 호출의 기본 동작은 유지한다.
- PDF: A4 3쪽, 모든 글자 11pt 이상, 한글 내장 글꼴, 전 페이지 샘플 표시. 발전소·측정 조건·소견·금액은 가상 값이며 원본 사진·고객 개인정보·실제 온도 측정값은 포함하지 않는다.
- 계정·조직·DB·Storage·인증·환경 설정·유료 플랜 변경 없음. 샘플 파일은 정적 공개 경로 하나이며 고객 파일 API를 공개하지 않는다.

## ✅ 검증

- 단위 시험 54개, lint, typecheck, 로컬 읽기 전용 HTTP 검사 31개 통과.
- 3쪽 모두 PNG로 렌더링해 한글·표제·수익 그래프·페이지 번호·여백·잘림 없음 확인. PDF 글자 좌표와 최소 11pt를 추가 검사.
- HTTP 검사는 27개 게스트 화면, 공개 PDF 바이트 일치, 비공개 파일 API 3개의 익명 요청 401 차단을 포함한다.
- 브라우저 인쇄 대화상자 조작·실물 프린터 출력·휴대폰 실기 시험은 이번 결과에 포함하지 않는다.
- 재생성: `cd demo-site && node scripts/generate-guest-report.mjs`. 정적 PDF가 소스에서 재생성한 결과와 다르면 단위 시험이 실패한다.

배포 준비 중. 성공 상태와 온라인 파일 일치 검증 후 출처를 추가한다.
