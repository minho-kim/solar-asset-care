# 열화상·가시광 검사 자료 처리 원칙

- 상태: 계약 전 준비 초안
- 작성일: 2026-08-25
- 주의: 이 문서는 계약 및 요구사항 확정 전 기술·업무 검토 자료다. 카메라 지원 범위, 온도 계산 방법과 진단 정확도는 샘플 검증 전 확정할 수 없다.

## 1. 확인된 내용

- 열화상·가시광 원본이 검사와 함께 접수된다.
- 촬영 위치, 촬영 조건과 설비 정보를 이미지와 함께 관리해야 한다.
- 자동 분석은 온도 이상 또는 고장 의심 영역을 제시하는 보조 기능이다.
- 최종 고장 판정, 판정 근거, 코멘트와 조치 권고는 전문가가 담당한다.
- 원본, 화면용 미리보기와 분석 파생 파일을 구분하고 원본의 체크섬·이력을 보존해야 한다.
- 열화상과 가시광의 자동 매칭에는 신뢰도와 수동 수정 기능이 필요하다.

## 2. 가장 큰 기술적 불확실성

열화상 파일이 단순 색상 이미지인지, 각 픽셀의 온도를 재계산할 수 있는 방사온도 원본인지에 따라 구현 가능 범위가 크게 달라진다. 같은 확장자여도 카메라 제조사·모델·촬영 설정에 따라 메타데이터와 SDK 지원이 다를 수 있다. 실제 원본과 제조사 문서를 확인하기 전에는 온도 컬럼, 임계값, 팔레트 해석이나 정확도를 확정하지 않는다.

## 3. 계약 전 기술 제안

### 3.1 원본 접수

- 브라우저 미리보기 가능 여부와 관계없이 전달받은 원본 바이트를 변경 없이 보존한다.
- 업로드 완료 시 파일 크기와 체크섬을 확인하고 검사·촬영 묶음·제출자를 연결한다.
- 파일명만으로 설비·촬영 순서·열/가시광 구분을 확정하지 않는다.
- 원본, 변환 미리보기, 썸네일, 온도 데이터 추출물과 분석 표시 이미지를 서로 다른 종류로 구분한다.
- 재업로드는 원본 덮어쓰기보다 새 제출과 무효/대체 관계로 남긴다.

### 3.2 촬영 맥락

진단에 필요한 후보 정보는 다음과 같지만, 필수 여부와 허용 범위는 카메라 전문가와 합의한다.

- 카메라 제조사·모델·장비 식별과 교정 정보
- 촬영 일시와 타임존
- 발전소·구역·어레이·설비 위치 표기
- 촬영 거리, 각도, 고도와 방향
- 날씨, 기온, 풍속, 구름, 일사량과 직전 운영 조건
- 방사율, 반사 겉보기 온도, 대기/거리 보정 등 카메라가 제공하는 방사온도 관련 값
- 촬영자, 비행/현장 묶음과 촬영 순서

사용자가 수기로 입력한 값, 카메라 원본에서 추출한 값과 외부 관측값을 구분해 출처를 남기는 방향을 제안한다.

### 3.3 열화상·가시광 짝 매칭

자동 매칭 후보는 다음 근거의 조합을 검토할 수 있다.

- 카메라가 함께 기록한 고유 식별 또는 촬영 묶음 정보
- 촬영 시간 차이와 순서
- 파일명·폴더 구조
- GPS/자세 정보가 신뢰할 수 있을 때의 공간 근접성
- 화면 특징의 유사성
- 현장 계획과 설비 위치 순서

시스템은 매칭 근거와 신뢰도를 보여주고 낮은 신뢰도·복수 후보·짝 누락을 자동 확정하지 않는 방향이 안전하다. 수동 수정 시 이전 관계, 수정자, 시점과 사유를 남긴다.

### 3.4 미리보기와 분석 입력

- 화면용 미리보기는 원본을 대체하지 않는다.
- 팔레트가 입혀진 화면 이미지와 실제 방사온도 데이터의 차이를 UI에서 혼동하지 않게 한다.
- 분석 전에 손상, 해상도, 온도 데이터 존재, 유효 범위와 필수 촬영 정보 누락을 확인한다.
- 지원하지 않는 원본을 일반 이미지로 변환해 온도 분석이 가능한 것처럼 표시하지 않는다.
- 분석 입력과 출력에 처리 도구·모델/규칙 버전, 시간과 경고를 연결한다.

### 3.5 자동 분석 보조

최초 MVP 후보는 다음 수준으로 제한하는 것이 적절하다.

- 온도 이상 또는 고장 의심 영역의 후보 표시
- 영역별 측정/비교값과 적용 조건의 설명
- 후보 신뢰도 또는 검토 우선순위
- 확대·팔레트/표시 전환·열/가시광 비교
- 전문가의 채택, 수정, 병합, 분리와 기각

분석 결과는 ‘고장 확정’이 아니라 검토 후보로 표현한다. 잘못된 양성·누락 가능성과 촬영 품질 한계를 함께 노출한다. 신규 모델 학습과 자동 예지 정비는 최초 MVP에서 제외한다.

### 3.6 전문가 판정

전문가는 최소한 다음 맥락을 한 작업 화면에서 비교할 수 있어야 한다.

- 변경되지 않은 원본과 화면용 파생물의 구분
- 대응 가시광 이미지와 매칭 신뢰도
- 촬영 조건과 누락 경고
- 발전소·설비·연결 구조와 위치
- 분석 후보의 근거와 처리 버전
- 같은 설비의 과거 검사·조치 이력(범위에 포함될 경우)

최종 진단에는 판정, 근거, 불확실성/제약, 조치 권고와 우선순위가 필요하다. 자동 후보를 바꾼 경우 원래 결과와 전문가 결정의 관계를 보존한다.

### 3.7 보고서 표현

- 고객이 자동 분석과 전문가 최종 판정을 혼동하지 않도록 구분한다.
- 사용한 검사 일시, 대상, 촬영 조건의 핵심과 자료 한계를 밝힌다.
- 대표 열화상·가시광, 표시 영역, 전문가 설명과 조치 권고를 일관되게 연결한다.
- 한글 글꼴과 모든 텍스트 최소 11pt를 적용하고 A4 페이지 넘침을 검증한다.
- 보고서 판본에는 발행·개정 관계를 표시하고 과거 판본을 덮어쓰지 않는다.

## 4. 추가 확인이 필요한 내용

### 4.1 반드시 받을 샘플

- 지원 후보 카메라별 원본 열화상 3개 이상과 대응 가시광
- 정상, 명확한 이상, 경계/판정 어려움, 짝 누락과 손상 사례
- 원본 그대로의 폴더 구조·파일명·제조사 뷰어 화면
- 촬영자가 실제로 기록하는 현장표와 설비 위치 자료
- 기존 고객용 보고서와 전문가의 판정 근거 예시

### 4.2 제조사·형식 질문

- 제조사, 모델, 펌웨어와 원본 확장자
- 방사온도 데이터 포함 여부와 제조사 SDK/라이선스
- SDK의 지원 OS, 서버 실행·재배포·동시 처리 제한
- 드론/카메라가 열화상·가시광을 동시에 촬영하는지
- GPS, 촬영 시각, 자세, 방사율 등 메타데이터의 실제 신뢰도

### 4.3 진단 품질 질문

- 이상 후보 유형과 전문가가 사용하는 기준
- 절대온도, 주변 대비, 동일 스트링/모듈 비교 등 판정 방법
- 촬영 조건별 분석 불가 또는 재촬영 기준
- 기대 정밀도·재현율과 허용 가능한 오탐/누락
- 전문가 간 판정 불일치와 2차 검토 방식

### 4.4 사용량 질문

- 검사당 이미지 수와 원본 평균/최대 용량
- 업로드 환경의 실제 네트워크 품질
- 월 검사량, 동시 분석 수와 결과 대기 목표
- 원본·파생물·보고서 보존 기간과 다운로드 빈도

## 5. 계약 전 기술검증 권고

1. 원본의 방사온도 데이터와 메타데이터를 손실 없이 읽을 수 있는지 확인한다.
2. 동일 파일의 체크섬 재현과 미리보기 분리를 확인한다.
3. 열/가시광 자동 매칭 품질을 실제 촬영 묶음으로 측정한다.
4. 전문가가 자동 후보를 수정·기각하는 화면 원형을 검토한다.
5. 샘플 보고서에서 한글·이미지·주석과 11pt/A4 조건을 확인한다.

이 검증 결과가 없으면 이미지 처리 난이도와 견적의 신뢰도가 낮다.
