# 공개 배포 전 로그인·보안·오류 점검

- 기준일: 2026-09-05
- 대상: solar-asset-care 로컬 운영 화면과 독립 Supabase 프로젝트
- 상태: 공개배포 보류. 기존 공개 데모는 변경하지 않았다.
- 상세 구현·시험 범위: [현재 개발 현황](DEVELOPMENT_STATUS_2026-09-05.md)

## 현재 결론

관리자·전문가·의뢰인의 주요 업무 흐름을 실제 세션으로 시험했다. 파일 업로드, 전문가 수동 판정, 촬영조건·서버 계산, 검토·승인·PDF 보관·발행·의뢰인 다운로드를 확인했다. 이것은 합성 자료 기반 1건의 개발 시험이며, 요구서 전체 구현이나 실제 고객 3건 검수 완료가 아니다.

## 확인한 보호 장치

| 항목 | 상태 |
|---|---|
| 로그인·비밀번호 변경 | 관리자 로그인 확인, 모든 역할에 내 계정 메뉴, 별도 계정으로 비밀번호 변경 회귀 시험 |
| 역할·소유권 | 관리자·배정 전문가·발전소에 연결된 의뢰인으로 제한 |
| 조직 간·사용자 간 격리 | 취소되는 SQL 시험 및 실제 Auth 세션·API 시험으로 확인 |
| 계산 기준·평가 쓰기 | 기준은 관리자만 새 판본 등록, 평가는 관리자·배정 전문가만 저장, 결과는 서버 재계산 |
| 촬영조건 | 조건 미달 시 보고서 검토 차단, 관리자만 사유 있는 예외 승인 |
| 판정 이력 | 수동 소견·수정·제외 담당자와 변경 전후 보관, 측정 온도에는 근거 필수 |
| 보고서 | 검토 시 내용 고정, 관리자 승인·PDF 보관 후 발행, 회수 시 의뢰인 접근 차단 |
| PDF 파일 | 비공개 저장, 내용 확인값 비교, 기존 파일 덮어쓰기 금지, 현재 보고서 권한으로 다운로드 |
| 마지막 관리자 | 활성 조직의 마지막 관리자 강등·정지·삭제 방지 유지 |
| 키·의존성 | 브라우저 publishable key만 사용, PDF 서버도 사용자 세션 사용, 패키지 정확한 버전·잠금 파일 유지 |
| 시간 | 촬영 입력을 한국시간으로 해석해 절대 시각 저장, 날짜 기간은 양 끝 포함·윤년 검증 |
| 보안 자동 진단 | 기존 유출 비밀번호 차단 미활성 경고 1건. 경고 0건 또는 보안 검수 완료로 보고하지 않음 |

PDF 시험 과정에서 한글 OTF 글꼴 호환 문제를 찾아 정적 TrueType으로 교체했다. 생성 PDF를 실제 렌더링해 A4·최소 11pt·한글/온도 단위·잘림 여부를 확인했다.

임시 계정·조직·업무 데이터·시험 파일은 삭제했다. 현재 사용자의 관리자 계정과 기존 운영 조직은 변경하지 않았다. 로그인·가입·초대 버튼을 누르는 모바일 UI 시험은 별도로 남아 있다.

## 공개 전에 남은 항목

1. 가입 확인·전문가/관리자 초대·비밀번호 재설정 메일의 실제 수신과 링크 만료·재사용·잘못된 주소 검사.
2. 실제 운영 도메인과 인증 복귀 주소 확정·연결. 운영 발신자/메일 서비스의 발송 제한·복구 절차 검증.
3. 관리자 MFA, 봇 방지와 유출 비밀번호 차단 검토. 유료 기능이나 플랜은 승인 없이 활성화하지 않는다.
4. Mac 잠금 해제 후 신규 화면의 모바일 조작·키보드·오류 복구·브라우저 인쇄 미리보기. 반응형 코드 적용을 실기 검수와 혼동하지 않는다.
5. 대용량 파일 재개·중단·실패·재시도, 임시 객체 정리, 악성·변조 파일과 초대 재시도 제한.
6. 고객용 이미지 마스킹과 검수본 공개, 카메라 원본별 온도 파서 검증. 일반 색상 이미지로 실제 온도를 단정하지 않는다.
7. DB·Storage 백업 및 별도 환경 복원, 권한 회수·파일 보존·파기·오류 감시.
8. 승인된 대표 자료 3건으로 의뢰·검토·발행·견적 비교·선택·후속 조치까지 종단 검수.

원본 파일의 해시 기록만으로 파일 형식 안전성·제조사 온도 정확성·모든 원본의 삭제 방지까지 보장한다고 표현하지 않는다. 이번 PDF 보관 보호 장치와 기존 원본 Storage 정책의 보강 범위는 구분한다.
